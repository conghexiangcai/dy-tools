## 本版修复

- 群成员扫描不再把简化的群资料当作 IM 群对象。完整 SDK 对象只缓存在原网页，按账号和 SDK 实例隔离；重启或刷新后从群目录恢复，再读取原成员游标。
- 增加 IM 初始化等待和缺失响应检查。读取失败显示目录／成员阶段、群名和游标；保留脱敏后的异常原因，不再只显示笼统的 IM_READ_FAILED。
- 各页面统一显示已核验的登录状态、昵称和“查看登录账号”；缓存账号与在线身份分开。切换账号及失效状态同步到各功能页面，迟到身份响应不能覆盖新会话。
- 分组目录读取不再要求个人 belong_groups。分组管家使用当前登录身份直接分页读取目录和成员，不依赖关注快照；个人分组设置仍严格要求可靠归属。
- 刷新返回明确结果，失败保留上次完整分组；初次关注分页显示已取得人数，完整后才展示名单。
- 软件及只读核查窗口统一禁止系统应用唤起权限，拦截主页面、子框架和重定向中的客户端协议，修复核查窗口遗漏造成的 Windows 打开应用提示。正常 HTTPS 页面继续打开。

## 保留的限制

- 分组新建、改名、删除仍未完成测试账号的真实写入验证，继续禁用。批量归属修改沿用原接口，本轮没有做真实修改。
- 粉丝列表候选接口的线上完整分页验证不属于本次修复，仍保留上一版未实测提示。
- 网络、权限或群人数变化导致名单不完整时，只保存已读取范围，不生成确定的成员减少结论。
- 发布包不包含个人数据库、会话副本、凭据或检查名单。原本机数据目录不变，全新安装仍为空。

开发检查：`npm ci`、`npm test`、`npm run smoke:fixes`、`npm run smoke:organization`、`npm run smoke:navigation`。后三项需要允许启动独立 Electron 窗口；测试使用单独的数据目录。打包后可运行 `node scripts/fixes-smoke.cjs --packaged` 与 `node scripts/navigation-smoke.cjs --packaged` 检查最新发布包。


使用旧版可能受平台接口变化影响；优先使用 2.4.3。未留存完整 ZIP 的中间构建仅提供源码，不以新版二进制冒充。
