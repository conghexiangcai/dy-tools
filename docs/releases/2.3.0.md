## 尚未完成真实实测的能力

1. **分组新建、改名、删除**：只有 APK 静态接口定义；改名字段枚举及真实提交／回读仍未验证。三个按钮禁用，不宣称可用，也不使用本地标签假装同步成功。需用单独测试账号验证后再开放。
2. **粉丝列表**：新增只读候选请求 `/aweme/v1/web/user/follower/list/`；当前会话下的分页、方向与完整人数未实测。页面明确显示待验证，只有结构、身份和全量人数检查通过才保存完整结果。失败保留不完整，不当作零粉丝。
3. **无关注名单时直接读取分组**：允许使用登录账号 sec_uid 作为目录上下文，仍需线上样本验证；若接口不接受会明确报错，不构造空分组成功。
4. **新增批量分组操作**：复用此前已有的成员设置和归属回读接口，本次只进行合成队列验证，没有调整真实账号分组，也没有执行真实取关。并发手机修改无法做到服务端事务，逐人读取后只修改指定来源／目标组并回读结果。

本轮尝试连接现有软件的本地调试端口时没有运行中的调试服务。随后申请启动真实会话只读核查程序，自动审批因用量上限未完成，程序未执行。未通过其他方式绕过审批或提取登录凭据。

## 使用边界

- 名单变化是两个采集时间之间的差异，不是准确事件时间或原因。
- 关注旧快照只有分页完成且当时总人数与实际行数相符才参与自动基准；历史种子名单不冒充实时采集。
- 数据源缺失、权限限制或成员变化导致不完整时，保留已读取内容，不能据此断言某人离开。
- 新增模块不创建每日任务。关闭软件不会自动继续批量写入，需要打开任务预览再确认。


使用旧版可能受平台接口变化影响；优先使用 2.4.3。未留存完整 ZIP 的中间构建仅提供源码，不以新版二进制冒充。
