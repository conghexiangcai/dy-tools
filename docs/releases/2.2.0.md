## 实测

- 桌面会话读取全部 48 个粉丝团与日历，正式解析器全部通过；未点亮的团仍纳入。
- 已授权的一个无圈子粉丝团普通签到成功，回读当天状态从未签到变为已签到、连续天数 0 变 1；没有自动入圈或批量提交。
- 独立 Node 成功核对本人 UID、完整读取 48 个团与日历：20 个今日已签到、17 个待签到、11 个需先入圈。纯只读、零 POST，数字为当时状态。
- 网页本人接口离开页面曾返回空白，改用 APK 本人资料接口后通过。普通签到实际为 `/ent/fandom/join/`、`join_type=3&action=1`，没有使用未核实的 `/sign/in` 枚举。

100 项单元和状态机测试通过，新增 21 项打卡测试：指定时点排序去重、间隔与跨日、大 ID、完整分页后才写、异常分页、未知状态、已签到跳过、需入圈跳过、超时回读、有限重试、验证码五秒等待、账号切换、进程锁、重启发送中回读及隔离保存。

桌面合成 UI 测试：10 个工具入口、时间预览保存、默认关闭、刷新、签到、状态筛选、导出和重启；勾选、打开记录、忽视名单保留。测试拦截真实网络与 Windows 任务创建，没有真实批量操作。
