# 2.4.3 标签窗口与资源释放验证

日期：2026-10-19。此版本只调整 Windows 主页查看窗口及标签操作，不修改采集接口、账号数据或数据库结构。

## 已完成

- TypeScript 编译通过；现有 170 项自动测试全部通过。
- 源码 Electron 实例通过 `scripts/browser-tabs-smoke.cjs`：真实创建窗口、WebContentsView 和原生 Menu 对象，由标签右键触发菜单，再调用实际菜单处理器。
- 覆盖关闭当前／其他／全部／左侧／右侧、边界菜单禁用、右键非当前标签、复制页面链接、复制标签页、重新加载、重复打开同一账号和延迟加载。
- 关闭最后一个标签、关闭窗口和关闭全部标签后，核对窗口、窗口自身 WebContents、所有主页 WebContents、两个本地浮层均为已销毁；主工具箱和独立采集窗口仍在。
- 覆盖快速关闭、重新打开、旧菜单回调、无效标签 ID、窗口关闭后主界面 IPC、重新创建后的账号资料回调。关闭范围一次完成，不依次加载待关闭标签。
- `scripts/maintenance-smoke.cjs` 回归通过：批量打开、静音、群成员资料合并、补全、导出、重启缓存、QQ 邮件配置与模拟发送去重；原勾选及历史打开记录保留。

## 测试边界

- 使用独立的模拟账号和测试数据目录；所有外部 HTTP 请求被拦截。没有真实关注、取关、改组、清理、签到或邮件发送，也没有读取真实登录数据库。
- 测试使用真实原生菜单对象和处理器，拦截菜单显示以避免占用用户操作；剪贴板写入以模拟接收器检查，不覆盖用户剪贴板。
- 远程网页加载被模拟为等待，验证批量打开不等待每个网页完成。源码本机两轮测试中新建框架到标签可用约 0.26～0.39 秒，复用现有窗口约 0.03～0.04 秒；这些是本地测试值，不包括抖音网络加载，也不是性能承诺。
- 验证的是页面和窗口资源被销毁；未将操作系统进程内存即时减少量作为判定。主软件、采集会话和共享 Chromium 运行时仍会占用内存。
- 打包后复测与文件校验结果见发布目录 `CHECKS-2.4.3.md`。

## 升级

使用旧版可能受平台接口变化影响；优先使用 2.4.3。未留存完整 ZIP 的中间构建仅提供源码，不以新版二进制冒充。
