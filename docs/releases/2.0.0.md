# 2.0.0 开发与验证说明

2026-10-06。遵照用户要求，本轮没有对现有真实账号执行关注、取关、取消点赞、取消收藏或撤销推荐。没有读取或复制现有登录状态到开发测试目录，也没有重启现有软件。

## 交付内容

- “抖音整理箱”首页，9 个独立入口，原关注清单与粉丝团查询仍保留。
- 当前筛选全部账号／具体分组全部账号的取关预览；固定范围、原生确认、账号绑定、逐项回读、暂停与恢复。
- 独立忽视名单，可恢复，不清除筛选、勾选和打开记录。
- 冻结原账号完整关注快照，在其他账号生成关注迁移预览；不改变原账号关系。
- 点赞、收藏作品、主动推荐作品的完整列表读取与清理队列。收藏限视频和图文作品，不包括音乐和合集。
- 导入多个粉丝群成员名单，按内部 UID 查重与导出；不把同名当同人，不把粉丝团或关注分组当聊天群。
- 原私密标识、分组、查询、导出等功能保留。数据目录名称未改，新增表与原记录分开。

## 检查依据及局限

- 取关路径复用此前已核实的网页接口；新增点赞、收藏、推荐列表及撤销路径、字段来源为匿名加载的抖音公开网页脚本。开发抓取不加载真实登录目录。静态代码可确认客户端调用方式，**不等于已用真实测试账号验证线上写入成功**。
- 推荐状态没有按不明枚举猜测；以本人推荐列表实际成员关系回读，长列表查询可能较慢。
- 所有写请求前绑定登录 UID、会话身份及固定预览；确认对话框默认“返回预览”。没有启动自动清理入口。
- 未知状态不发送修改；写超时先回读，不盲目重放。确认前后账号变化、暂停、网络失败、验证码等保存断点。验证码确认后等待 5 秒。
- **自动读取粉丝聊天群成员接口尚未验证，本版只提供成员名单导入查重。** 页面和使用说明公开此限制。真实读写测试应使用用户指定的测试账号。
- 粉丝团旧版限制保留：关系服务可能空响应，会员／守护缺少有效线上对照时显示未知。
