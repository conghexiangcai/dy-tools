# 抖音整理箱 2.4.2 验证说明

日期：2026-10-19（北京时间）。

## 本次更新

- 批量主页采用按需加载：先建立全部标签，只加载当前页；固定显示关闭按钮。切换后其他标签静音，关闭标签释放 WebContents，关闭查看窗口释放全部主页和播放页面。原打开记录仍表示请求打开，不等同于加载完成或已取关。
- 群成员按 UID 合并多个群已有的昵称、群昵称、sec_uid 和抖音号；检索和导出增加抖音号。本地关注资料、独立账号资料缓存可补充显示。缺少资料的检索结果可按需读取、暂停及继续；身份不符不写入，连续三个成员失败后暂停。
- 粉丝团打卡增加 QQ 邮件失败汇总告警，桌面及服务器均支持。默认关闭；手动测试独立于签到。邮箱授权码与抖音凭据分开，桌面系统加密、CLI 私有文件或环境变量，均不写入名单导出。
- 修复启动时快速切换功能页触发 ERR_ABORTED 被误报为启动失败。只有被新页面替代的加载中断会被忽略，真正加载失败仍报错。

## 自动检查

- TypeScript 构建及 170 项 Node 测试通过，包含旧功能回归。
- SMTP 使用模拟连接验证分片与多行响应、LOGIN 认证、DATA 后确认、认证失败、明确拒绝、连接中断及超时。发送结果不明保持未知，不自动重复发送相同告警。
- 验证默认关闭、地址和头部注入校验、失败汇总、只读与主动暂停不发送、冷却去重、并发抢占、不同账号隔离、CLI 凭据文件替换和环境变量读取、发信失败不改变签到结果。
- 群资料检查跨群及导入两侧合并、保留 UID 精度、Excel 新旧格式兼容、账号字段往返、缓存持久化与隔离、资料身份核对、账号切换丢弃迟到响应、有限重试及连续失败暂停。资料补全不修改旧群成员快照。
- 启动导航检查快速切换取消旧加载，以及真实资源错误不能被吞掉。

## 界面检查

使用独立合成数据库和 Playwright 驱动 Electron；屏蔽所有远程 HTTP 请求，模拟 SMTP 发送，不使用用户真实登录或名单。

- 即使网页加载始终未完成，一批五个主页仍立即返回；只加载选中的标签，其他标签按需加载。长标题关闭按钮可见；标签关闭和窗口关闭释放页面，后台标签静音。
- 查重结果从其他群及本地关注数据补充资料；只对仍缺资料的匹配成员发起查询。抖音号搜索、结果导出、退出重启后复用缓存通过。旧快照保持原样。
- 邮箱默认关闭，保存时清空授权码输入，数据库及前端状态不含授权码明文；修改间隔并留空授权码保持原认证。模拟测试邮件、失败告警及重复通知抑制通过，重启后设置保留。
- 快速进入群检索不再弹启动失败。原勾选、打开记录和历史成员快照保留。

## 实测边界

本轮没有连接真实 QQ 邮箱发送邮件；需要用户在本地填写发件邮箱、SMTP 授权码和收件地址，再主动点击测试邮件或执行 `--test-mail`。服务器端只有模拟认证与发信测试，不把它标为真实投递成功。

群资料补全沿用现有账号解析与身份核验接口，本轮使用合成响应检查流程，没有批量访问真实群成员。抖音未返回的字段仍是未知，不能保证每个账号都能补齐。

没有执行真实签到、关注、取关、分组更改、互动清理或发送聊天消息。发行包不包含数据库、登录会话或用户凭据。安卓、iOS 不属于本次交付。
