# 2.1.0 验证说明

日期：2026-10-08。真实账号验证仅执行读取；没有执行关注、取关、点赞／收藏／推荐清理、加群、退群或发送消息。没有读取聊天消息正文。

## 真实接口

- 复用独立登录会话，核对网页本人 UID 与网页 IM SDK 账号一致。
- 从抖音实际加载的公共 SDK 确认 `getUserConversationList` 对应 `https://imapi.douyin.com/v1/conversation/list`（命令 2006），`getConversationParticipantsByPage` 对应 `/v1/conversation/participants_list`（命令 605）。调用限定为这两个只读方法，沿用 SDK 签名和会话，不导出 Token。
- 群目录以 GROUP_CHAT=2、inboxType=0、sortType=1、withCold=true 分页读取，35 个群、4 页；不是最近聊天缓存。普通群与粉丝群均保留；群分类尚未核实，统一显示未知。
- 47 人群读取 47 个唯一 UID；500 人群按 200 / 200 / 100 三页返回，去重后 500 人，包含当前登录账号，500 人均有 sec_uid。成员返回的群 ID 与请求一致。
- 最终页面请求代码在同一会话中实际返回身份匹配的成员。仅返回群资料与成员身份字段；不将 SDK 上下文、凭据、聊天正文或其他会话内容返回本地界面。
- 用户提供的两个短链均已展开并取得资料。作品短链识别作品作者、主页短链识别主页本人；作者 UID 与主页详情身份匹配。
- 修复 Electron `Session.fetch` 手动重定向报 `Redirect was cancelled`：改用 `ClientRequest` 读取重定向，每一跳先校验官方 HTTPS 域名，不唤起客户端协议。

## 自动检查

- 79 项单元测试通过，覆盖分享文案与转义冒号、多个链接拒绝、图文作品、作者身份、字符串大 ID、缺失 UID、跨群重复、同名不同人、历史快照去重、部分名单未知、并集比较。
- JSON / XLSX 导出后重新导入；Excel ID 保持文本，外部列映射，数值精度损坏、公式和昵称单独列入待处理。
- 扫描分页、网络重试、断点、关闭恢复、重复游标、人数冲突、验证码后等待五秒、切换账号丢弃迟到响应；原使用记录保留。
- Electron 页面检查使用合成数据，验证默认不选群、导入、查重、扫描、比较、作品作者卡片与私密标识、Excel 导出；全部远程请求被阻断。

## 已知限制

- 网页 IM 组件需已加载。软件提示未就绪时，在登录窗口点击顶部“消息”，待组件载入后重试；无需进入具体聊天。
- 网页接口返回的成员常无昵称，保留 UID / sec_uid / 群昵称，缺失显示“未提供昵称”；不逐人请求主页补齐，避免让扫描变成大量主页采集。
- 群类型尚未核实，显示未知。完整性依据分页结束和目录人数一致；扫描期间人数变化或权限限制会保留不完整结果。
- 验证码、断网和切换账号采用合成条件检查，未为测试故意触发真实账号风控。
- 分享作品失效、作者资料不可读取时保留错误，不从推荐作品、评论者或分享者猜测身份。
- 新增功能均为只读；此前批量修改功能仍要求用户在各功能中确认执行，本次未拿真实账号测试写入。


使用旧版可能受平台接口变化影响；优先使用 2.4.3。未留存完整 ZIP 的中间构建仅提供源码，不以新版二进制冒充。
