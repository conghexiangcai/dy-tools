# 抖音整理箱

Windows 10 / 11，64 位免安装软件。解压完整文件夹，双击 **抖音整理箱.exe**。无需安装 Python、Node，也无需聊天助手保持运行。

2.4.3 增加浏览器式标签右键菜单，并在关闭主页窗口或最后一个标签时彻底释放窗口和网页。保留 2.4.2 的 QQ 邮件失败告警及群成员资料补全。升级先退出旧版，解压新版到独立目录启动；本机数据目录仍为 DouyinFollowingReview，保留原名单、勾选、打开记录、忽视名单和历史任务。

## 本次更新（2.4.3）

- **真正关闭**：关闭主页窗口、最后一个标签或全部标签，会销毁该窗口、网页和分组／私密标识视图，停止音视频并释放这些页面资源；主工具箱及独立采集窗口继续运行。再次打开主页会重新创建查看窗口，复用登录会话。
- **标签右键菜单**：重新加载、复制标签页、复制页面链接、关闭当前、关闭其他、关闭左侧、关闭右侧、关闭全部。关闭范围以右键点击的标签为准；没有左侧／右侧／其他标签时相应菜单禁用。复制标签页会在原标签右侧打开同一页面。
- **切换与资源**：批量建立标签仍只加载当前页；未激活的标签保持静音。批量关闭一次处理全部目标，不逐个加载即将关闭的页面。关闭标签和窗口不删除名单、勾选或打开记录。
- **重新打开耗时**：本机隔离测试中，重新创建窗口到标签栏可用约 0.3～0.4 秒；此数值不包含抖音网页加载时间。不同电脑负载下会变化。关闭窗口释放其资源，但主软件、采集会话及共享运行时仍会使用内存。

## 上次更新（2.4.2）

- **启动切页**：修复页面未加载完就进入其他功能时弹出 ERR_ABORTED 启动失败的问题。
- **主页标签**：点击“打开下一批”立即建立标签，只加载当前标签，切换时再加载其他主页。每个标签都有固定的 × 关闭按钮，不会被长标题挤掉。未选中的标签静音；关闭标签释放对应页面，关闭查看窗口释放其中全部页面和媒体。2.4.3 已改为关闭最后一个标签时销毁空窗口。采集登录窗口保持独立。
- **打开记录口径**：仍表示“已请求打开主页”，建立待查看标签即记录，不表示主页已经加载完成或已取关。关闭标签不清空打开记录；需要时使用“重开上一批”。
- **群成员资料**：跨群查重和导入比较按 UID 合并已有昵称、群昵称、sec_uid、抖音号；优先补用当前账号的关注名单和已有资料缓存。结果新增“抖音号”列，可搜索，JSON／Excel 同步导出，外部 Excel 支持映射该列。原格式继续兼容。
- **按需补全**：检索后点“补全本次结果资料 / 继续”，仅查询本次结果中缺少昵称或抖音号的成员，不重新扫描群。每次至少间隔一秒，身份一致才保存；普通空响应最多重试两次，连续三个成员失败后暂停。可点“暂停”，之后再次补全；验证码完成后确认并等待五秒。缓存按登录账号保存，重启后再次检索可复用；旧的成员历史快照不被改写。
- **未知资料**：抖音未返回抖音号或资料受限时仍显示“未知”，不拿内部 UID 充当抖音号，也不会根据昵称猜人。是否在群内仍按成员快照判断，不因资料补全改变群归属或完整性。

## QQ 邮件失败告警

进入“粉丝团打卡”→“失败邮件告警”。填写完整发件邮箱（QQ 或 Foxmail）、SMTP 授权码和收件邮箱，保存后可点击“发送测试邮件”。自动告警默认关闭，需要勾选启用。QQ SMTP 服务固定为 smtp.qq.com:465，通过 TLS 连接；在 QQ 邮箱设置中开启 SMTP 并获取授权码，不能使用 QQ 登录密码。无需提供凭据给聊天助手。

- 每轮签到失败、认证失效、验证码、限流或未确认结果汇总通知；只读核查、主动暂停和账号切换不触发。默认不报告“需要先加入圈子／暂不支持”，可单独勾选。
- 同账号、同日、同类失败默认 60 分钟内不重复通知（可改为 10～1440 分钟）。冷却结束后，在后续运行或定时检查发现该问题仍存在时再提醒；不会单独创建邮件定时任务。
- SMTP 发送失败会显示原因，打卡记录不丢失。发送后连接断开而无法确认接收时显示“送达未知”，不盲目重发同一条；请检查邮箱和垃圾箱。“QQ 邮箱已接受”表示服务器接收，不保证已进入收件箱。
- 桌面授权码使用 Windows 系统加密保存，不回显、不导出。替换时填写新授权码再保存；留空保留已有授权码。切换发件邮箱需要对应的新授权码。
- 服务器使用独立配置和授权码文件，支持纯 CLI 的 --test-mail 命令，详见服务器包“使用说明.md”。桌面和服务器各自保留发送记录，不进行跨设备去重；如果两边同时启用，同一故障可能各收到一封。

本版通过模拟 SMTP 的认证、发送、断线、超时及重复通知测试，没有使用真实邮箱实发。需要配置自己的邮箱后点击测试邮件确认投递。
